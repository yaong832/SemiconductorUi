# 추이 창 사용법 (챔버 온도·압력 그래프)

추이 창은 공정 중 **Chamber A / B / C**의 **온도**와 **압력**이 어떻게 변했는지 시간 그래프로 보여 줍니다.
메인 화면 PM 상태 카드에 나오는 온도·압력 값을 시간 순서대로 이어 그린 것입니다.

## 1. 여는 법
1. 화면 아래 메뉴에서 **추이**를 누릅니다.
2. 창이 열리면 바로 그래프가 그려지고, 열려 있는 동안 1초마다 새로 그려집니다.
3. 다 보면 창 오른쪽 위 **X**로 닫습니다.

> ⚠️ **장비 공정 중에는 확인 후 바로 닫으세요.**
> 추이 창이 떠 있는 동안에는 메인 화면을 누를 수 없습니다. 메인 화면의 **긴급 정지** 버튼도 누를 수 없습니다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│ 표시 구간 [최근 10분 ▼]   기록 13:02:11 ~ 13:15:40 (1초 간격) … │
│                 ── PV (현재값)   ‐ ‐ SV (레시피 설정값)          │
├───────────────────────────────┬──────────────────────────────┤
│ Chamber A 온도 (°C)  PV / SV   │ Chamber A 압력 (Torr) PV / SV │
├───────────────────────────────┼──────────────────────────────┤
│ Chamber B 온도 (°C)  PV / SV   │ Chamber B 압력 (Torr) PV / SV │
├───────────────────────────────┼──────────────────────────────┤
│ Chamber C 온도 (°C)  PV / SV   │ Chamber C 압력 (Torr) PV / SV │
└───────────────────────────────┴──────────────────────────────┘
```

- **위쪽 줄**
  - **표시 구간**: 가로축에 보여 줄 시간 범위입니다. 최근 5분 / 10분 / 30분 / 1시간 / 전체 중에서 고릅니다. 처음에는 최근 10분입니다.
  - 오른쪽 글자: 기록이 언제부터 언제까지 있는지 알려 줍니다.
- **그래프 6칸**: 챔버마다 한 줄씩 있고, 왼쪽 칸이 온도, 오른쪽 칸이 압력입니다.
  - 챔버마다 압력 크기가 크게 달라서(예: 760 / 0.005 / 50 Torr) 그래프 칸을 따로 나눴습니다.
- **각 그래프 제목**: 가장 최근에 기록된 PV와 SV 숫자입니다. 값이 없으면 `-`로 표시합니다.
- 창 크기는 마우스로 늘리거나 최대화할 수 있습니다.

## 3. 선 읽는 법

| 선 | 뜻 | 언제 보이나 |
| --- | --- | --- |
| 파란 **실선** (PV) | 현재값 | 그 챔버에서 **공정이 진행 중인 동안**만 |
| 주황 **점선** (SV) | 레시피 설정값 | **레시피를 적용한 뒤**에만 |

- 웨이퍼가 없거나 도어가 열려 있는 등 그 챔버가 공정 중이 아닐 때는 파란 선이 **끊깁니다**. 오류가 아닙니다.
  - 메인 화면 PM 카드에서 PV가 `-`로 나오는 때와 같습니다.
- 파란 선이 주황 점선 근처에 붙어 있으면 설정값대로 진행 중이라는 뜻입니다.

## 4. 언제 기록되나
- **공정이 진행 중일 때만** 1초에 한 번 세 챔버 값을 함께 기록합니다.
  - 공정 전, 공정이 끝난 뒤, **일시정지 중**에는 기록하지 않습니다. 그 구간은 그래프가 비어 있습니다.
- 추이 창을 열어 두지 않아도 기록합니다. 공정 중간에 창을 열어도 공정 시작부터의 선이 보입니다.
- **최근 2시간치만** 남기고, 그보다 오래된 기록은 자동으로 지웁니다.
- 기록은 프로그램 메모리에만 있습니다. **프로그램을 끄면 사라지고**, 파일로 저장되지 않습니다.
  - 공정 기록을 남겨야 하면 하단 메뉴 **보고서**의 **Export CSV**(로그)나 **웨이퍼 이력**을 쓰세요.

## 5. 알아 둘 것
- **온도·압력 PV는 장비 센서에서 읽은 값이 아닙니다.**
  - 이 장비에는 온도·압력 센서가 연결되어 있지 않습니다.
  - 그래서 프로그램이 공정 중에 레시피 설정값 근처에서 값을 만들어 냅니다.
  - 그래프는 실제 챔버 상태가 아니라 **"어느 챔버가 언제 공정 중이었는지, 레시피 설정값이 무엇이었는지"**를 보는 용도로 쓰세요.
  - 메인 화면 PM 카드에 나오는 PV도 같은 값입니다.
- 하드웨어 모드(EtherCAT 연결)와 시뮬레이션 모드 모두 같은 방식으로 기록합니다.

## 6. 이럴 때는

| 증상 | 이유 / 할 일 |
| --- | --- |
| "아직 기록이 없습니다…"만 보임 | 프로그램을 켠 뒤 아직 공정을 시작하지 않았습니다. 공정을 시작하면 기록됩니다. |
| 주황 점선이 없음 | 레시피를 적용하지 않았습니다. 메인 화면 오른쪽 제어 패널의 **레시피 및 작업 설정** 칸에서 **레시피 적용**을 누르세요. |
| 파란 선이 군데군데 끊김 | 그 챔버가 공정 중이 아니던 구간입니다 (웨이퍼 없음, 도어 열림, 공정 완료 대기 등). 정상입니다. |
| 그래프가 거의 비어 있음 | 표시 구간이 너무 짧을 수 있습니다. **전체**로 바꿔 보세요. |
| 어제 공정 그래프가 없음 | 기록은 최근 2시간치만, 그리고 프로그램이 켜져 있는 동안만 남습니다. |
| 창을 열 때 로그에 `Trend 폼 오류`가 남음 | 화면 캡처와 로그를 개발 담당자에게 보내 주세요. |
