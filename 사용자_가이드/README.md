# 사용자 가이드

이 프로그램(웨이퍼 이송 장비 제어 UI)을 **처음 쓰는 사람**을 위한 안내서입니다.
화면 위치, 버튼 순서, 막혔을 때 할 일을 순서대로 적었습니다.

## 처음이라면 이 순서로 읽으세요

| 순서 | 문서 | 내용 |
| --- | --- | --- |
| 1 | [01_처음_시작하기.md](01_처음_시작하기.md) | 화면 둘러보기, 로그인, 첫 공정을 시뮬레이션으로 따라 하기, 실제 장비로 돌리기, 끝내기 |
| 2 | [02_멈춤과_알람.md](02_멈춤과_알람.md) | 긴급 정지, 일시 정지, 알람 리셋, 공정 리셋. **장비를 움직이기 전에 꼭 읽으세요.** |
| 3 | [03_추이_창.md](03_추이_창.md) | 챔버 온도·압력 그래프 보는 법 |

## 꼭 기억할 세 가지
1. **처음에는 시뮬레이션으로 연습하세요.** EtherCAT을 연결하지 않고 공정을 시작하면 장비는 움직이지 않고 화면에서만 공정이 진행됩니다.
2. **급하면 오른쪽 제어 패널의 빨간 `긴급 정지`를 누르세요.** 두 축 서보가 바로 꺼집니다.
3. **레시피·유지보수·설정·추이·보고서 창이 떠 있는 동안에는 메인 화면의 긴급 정지를 누를 수 없습니다.** 장비가 움직이는 중에는 이 창들을 열지 말거나, 확인 후 바로 닫으세요.
